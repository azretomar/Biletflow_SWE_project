# BiletFlow

Self-service event ticketing platform for Kazakhstan (CSCI 361, Team 5).

## Tech stack
- Backend: Go
- Web frontend: React (Vite)
- Mobile check-in app: Flutter
- Design: Canva mockups
- Task tracking: Jira

## Priority flow
Create event, register for a ticket, receive a QR ticket, check in at the event.

## Run the frontend locally
cd frontend
npm install
npm run dev
